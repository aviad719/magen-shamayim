# מגן שמיים 🛡️

משחק הגנה אווירית בדפדפן (tower defense) על מפת לוויין אמיתית של המזרח התיכון: רחפנים, מל״טים, טילי שיוט וטילים בליסטיים מאיראן ומתימן, ומולם כיפת ברזל, מגן אור, שרביט קסמים, חץ – ומגל 4 גם חיל האוויר (F-15 / F-35) שתוקף אתרי שיגור.

🎮 **לשחק עכשיו:** https://magen-shamayim.sites.tab.bot/
(בטלפון – לסובב לרוחב)

## גרסה נוכחית: 0.3
- יהודה ושומרון והגולן – שטח ישראל לכל דבר, אפשר לבנות בהם הגנות
- 6 ערים (כולל פרדס חנה) + בסיסי רמת דוד ונבטים שמתעוררים בגל 4; 5 פגיעות לכל עיר ובסיס, המשחק נגמר רק כשכל הערים נופלות
- 13 אתרי שיגור מתמחים באיראן ובתימן (רחפנים ומל״טים / מל״טים ושיוט / בליסטיים ושיוט)
- אתר שהותקף: מושבת ← בשיקום 50% ← פעיל מלא (תקיפה חוזרת מאפסת)
- 3 רמות קושי, שמירה אוטומטית אחרי כל גל ושיא אישי

## הרצה מקומית
המשחק הוא HTML/JS נקי, בלי שלב בנייה ובלי תלויות.

- הכי פשוט: לפתוח את `tower-defense/site/index.html` בדפדפן.
- או עם שרת סטטי:
  ```
  cd tower-defense/site
  python3 -m http.server 8000
  ```
  ואז לגלוש ל־http://localhost:8000

### בדיקות
```
node --test tower-defense/test/*.test.js
```
(Node 18 ומעלה)

## מבנה התיקיות
```
tower-defense/   מגן שמיים – משחק ההגנה האווירית
  site/          קוד המשחק (index.html, game.js, geo.js, styles.css, map.jpg – מפת לוויין של NASA)
  test/          בדיקות אוטומטיות
rts/             בקרוב: משחק האסטרטגיה – חזית לבנון (בסגנון Generals)
```

הכסף שמרוויחים במגן שמיים יעבור למשחק האסטרטגיה, וערים שנכבשות שם יתווספו למפת מגן שמיים.
