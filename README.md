# מגן שמיים 🛡️

משחק הגנה אווירית בדפדפן (tower defense) על מפת לוויין אמיתית של המזרח התיכון: רחפנים, מל״טים, טילי שיוט וטילים בליסטיים מאיראן ומתימן, ומולם כיפת ברזל, מגן אור, שרביט קסמים, חץ – ומגל 4 גם חיל האוויר (F-15 / F-35) שתוקף אתרי שיגור.

🎮 **לשחק עכשיו:** https://magen-shamayim.sites.tab.bot/
(בטלפון – לסובב לרוחב)

## 🆕 חזית לבנון – משחק אסטרטגיה (שלב 1)
🎮 **לשחק:** https://magen-shamayim.sites.tab.bot/rts/ (טלפון, לרוחב)

משחק בסגנון Generals, דו־ממד מלמעלה, על מפה אמיתית מהגליל ועד ביירות (חוף, הליטני וגשריו, יערות, כפרים וערים).
- ישראל: מחלקות של 8 – גולני (שטח בנוי), נח״ל (יער), גבעתי (הגנה); הנדסה בונה עמדות רואה־יורה ומתקנת שריון; מרכבה עם מעיל רוח; נמר נושא עד 2 מחלקות; מל״ט סיור, מל״ט תקיפה, מסוק (מוביל מחלקה) ומטוס קרב
- אחד / פצל (חצי־חצי: 8 ← 4+4 ← 2+2) לכל סוגי היחידות, העלה / הורד לנמר ולמסוק
- חיזבאללה: מוצבים מחופרים ביערות, כפרים שמייצרים חי״ר וג׳יפים (מקלע / נ״ט / נ״מ), ערים עם נגמ״שים וטנקים, רחפני נפץ מכל בסיס, מתקפות נגד, 3 רמות קושי
- ערפל קרב, מיני־מפה, שמירה והמשך, השהיה ומהירות ×2
- **חיבור בין המשחקים:** הכסף מגלי מגן שמיים נכנס ל״תקציב מלחמה״ משותף שעובר לחזית; כיבוש צור / צידון / ביירות מוסיף אותן כעיר ישראלית (5 פגיעות) במפת מגן שמיים. כיבוש ביירות = ניצחון בחזית.

## מגן שמיים – גרסה 0.3
- יהודה ושומרון והגולן – שטח ישראל לכל דבר, אפשר לבנות בהם הגנות
- 6 ערים (כולל פרדס חנה) + בסיסי רמת דוד ונבטים שמתעוררים בגל 4; 5 פגיעות לכל עיר ובסיס, המשחק נגמר רק כשכל הערים נופלות
- 13 אתרי שיגור מתמחים באיראן ובתימן (רחפנים ומל״טים / מל״טים ושיוט / בליסטיים ושיוט)
- אתר שהותקף: מושבת ← בשיקום 50% ← פעיל מלא (תקיפה חוזרת מאפסת)
- 3 רמות קושי, שמירה אוטומטית אחרי כל גל ושיא אישי

## הרצה מקומית
המשחק הוא HTML/JS נקי, בלי שלב בנייה ובלי תלויות.

- הכי פשוט: לפתוח את `tower-defense/site/index.html` בדפדפן.
- או עם שרת סטטי:
  ```
  cd tower-defense/site
  python3 -m http.server 8000
  ```
  ואז לגלוש ל־http://localhost:8000

### שני המשחקים יחד (כמו באתר)
```
sh build.sh
python3 -m http.server -d dist 8000
```
מגן שמיים ב־http://localhost:8000 וחזית לבנון ב־http://localhost:8000/rts/ (אותו origin, לכן התקציב והערים משותפים).

### בדיקות
```
node --test tower-defense/test/*.test.js rts/test/*.test.js
```
(Node 18 ומעלה)

## מבנה התיקיות
```
tower-defense/   מגן שמיים – משחק ההגנה האווירית
  site/          קוד המשחק (index.html, game.js, geo.js, styles.css, map.jpg – מפת לוויין של NASA)
  test/          בדיקות אוטומטיות
  site/shared.js שמירה משותפת לשני המשחקים (תקציב מלחמה, ערים שנכבשו)
rts/             חזית לבנון – משחק האסטרטגיה (בסגנון Generals)
  js/data.js     מפה, יחידות, אתרים ורמות קושי (נתונים בלבד)
  js/sim.js      הסימולציה – בלי DOM, כדי שאפשר יהיה להחליף לרנדרר תלת־ממדי בהמשך
  js/render.js   רנדרר Canvas דו־ממדי
  js/main.js     ממשק טלפון ומחוות מגע
  test/          בדיקות יחידה + בוט שמשחק עד הניצחון
build.sh         מרכיב את האתר המלא לתיקיית dist/
```

הכסף שמרוויחים במגן שמיים עובר למשחק האסטרטגיה, וערים שנכבשות שם מתווספות למפת מגן שמיים.
